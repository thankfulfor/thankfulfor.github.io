<div class="about-section">

<p class="about-section__lead">
  Перехожу в техническое писательство из веб-вёрстки и frontend-разработки.
  Около девяти лет работала в продуктовых IT-командах. Фокус — API, developer documentation и docs-as-code.
</p>

<p>
  Моя сильная сторона — самостоятельное исследование продукта: сопоставляю требования, интерфейс, REST API и JSON,
  фактические запросы и при необходимости код. Нахожу противоречия, точечно уточняю логику у разработчиков,
  аналитиков и QA и фиксирую результат в документации.
</p>

<p>
  В коммерческих командах работала с внутренней документацией, troubleshooting, техническими постановками задач
  и структурами данных. API-документацию и docs-as-code развиваю отдельным направлением в портфолио.
</p>

<ul class="about-section__facts">
  <li>Исследую REST API как потребитель со стороны frontend: проверяю запросы и ответы, ошибки и пограничные состояния через DevTools, JSON, curl и Swagger/OpenAPI.</li>
  <li>В коммерческой работе использовала Confluence, Jira и YouTrack; портфолио веду в Markdown и Git и публикую через GitHub Pages.</li>
  <li>Хорошо понимаю жизненный цикл продуктовой задачи и взаимодействие frontend/backend, поэтому могу самостоятельно исследовать техническую часть и предметно обсуждать её с разработчиками.</li>
</ul>
