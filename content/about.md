# Обо мне

<div class="about-section">

<p class="about-section__lead">
  Перехожу в техническое писательство из веб-вёрстки и frontend-разработки. Имею около девяти лет опыта работы
  в продуктовых IT-командах. Специализация — API-документация, документация для разработчиков и docs-as-code.
</p>

<p>
  Ключевая компетенция — самостоятельное исследование продукта: сопоставляю требования, интерфейс, REST API и JSON,
  фактические запросы и при необходимости код. Выявляю противоречия, уточняю логику у разработчиков,
  аналитиков и QA и фиксирую результат в документации.
</p>

<p>
  Коммерческий опыт включает подготовку и актуализацию внутренней технической документации,
  troubleshooting-инструкций, технических постановок и описаний структур данных. API-документацию и docs-as-code
  развиваю как отдельное направление в портфолио.
</p>

<ul class="about-section__facts">
  <li>Исследую REST API со стороны frontend-клиента: проверяю запросы и ответы, обработку ошибок и пограничные сценарии с помощью DevTools, JSON, curl и Swagger/OpenAPI.</li>
  <li>В коммерческой работе использовала Confluence, Jira и YouTrack; портфолио веду в Markdown и Git и публикую через GitHub Pages.</li>
  <li>Имею практическое понимание жизненного цикла разработки ПО (SDLC) и взаимодействия frontend/backend. Могу самостоятельно исследовать техническую часть продукта и предметно обсуждать решения с разработчиками.</li>
</ul>
