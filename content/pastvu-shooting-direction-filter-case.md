## Контекст

[PastVu](https://pastvu.com/) — open-source онлайн-архив исторических фотографий. Пользователи могут искать фотографии по месту, времени и другим признакам.

В этом кейсе разбирается новая пользовательская фича: фильтр «Изображение имеет направление съёмки». Фильтр был предложен в issue #734 и реализован в PR #796.

## Пользовательская задача

Фильтр «Изображение имеет направление съёмки» помогает находить фотографии с указанным направлением съёмки и без него; вариант «Нет» полезен, например, для интерьерных снимков и фотографий с известным местом, но без точной точки съёмки.

## Инструкция пользователя

1. Откройте главную страницу PastVu и нажмите «Галерея».
2. В блоке фильтров найдите параметр «Изображение имеет направление съёмки».
3. Выберите нужное значение:

   **«Да»** - чтобы показать фотографии с указанным направлением съёмки.

   <img class="case-image-75" src="/images/cases/shooting-direction-filter/filter-direction-yes.png" alt="В фильтре PastVu выбрано значение Да для параметра Направление съёмки">

   **«Нет»** - чтобы показать фотографии без указанного направления. Например, интерьерные снимки или фотографии с известным местом, но без точной точки съёмки.

   <img class="case-image-75" src="/images/cases/shooting-direction-filter/filter-direction-no.png" alt="В фильтре PastVu выбрано значение Нет для параметра Направление съёмки">

## Почему общий переключатель не вошёл в инструкцию

При проверке интерфейса я увидела общую кнопку «Отключить фильтр». Она делает неактивной всю панель, включая параметр направления съёмки, но не сбрасывает выбранные значения.

Этот результат важен для кейса: он показывает, почему кнопку нельзя включать в инструкцию по конкретному фильтру. Иначе пользователь может принять отключение всей панели за способ изменить или сбросить условие направления съёмки.
