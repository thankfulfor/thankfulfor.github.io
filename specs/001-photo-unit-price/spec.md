# Спецификация: цена за килограмм или литр по фото

## Задача

Покупателю нужно быстро сравнить товары разного веса или объёма. Страница принимает фото ценника или упаковки, распознаёт общую цену и количество товара, затем показывает цену за килограмм или литр.

## Пользовательские сценарии

1. Пользователь открывает камеру, фотографирует ценник и получает расчёт.
2. Пользователь загружает готовое фото и получает расчёт.
3. Пользователь исправляет неверно распознанную цену, количество или единицу измерения; результат пересчитывается сразу.
4. Если распознавание не нашло оба значения, пользователь видит понятное сообщение и может заполнить поля вручную.

## Требования

- Работает на GitHub Pages без собственного сервера.
- Поддерживает единицы `г`, `кг`, `мл`, `л`.
- Показывает цену за `1 кг` для массы и за `1 л` для объёма.
- Фото обрабатывается в браузере и не загружается в репозиторий или на сервер сайта.
- Камера запрашивается только после действия пользователя.
- Есть доступная альтернатива камере — обычная загрузка файла.
- Результат нельзя выдавать за точный без возможности проверить исходные значения.

## Критерии готовности

- Страница открывается по `/unit-price/` после сборки Hugo.
- Камера запускается в браузере с поддержкой `getUserMedia` на HTTPS.
- После загрузки изображения доступна кнопка распознавания.
- Корректно считаются как минимум: `199 ₽ / 500 г = 398 ₽/кг` и `159,90 ₽ / 0,9 л = 177,67 ₽/л`.
- При нулевых, отрицательных или пустых значениях результат не показывается.
- Интерфейс помещается на экране телефона шириной 320 px без горизонтальной прокрутки.

## Вне первой версии

- История расчётов и учётные записи.
- Сравнение нескольких товаров на одном экране.
- Облачное распознавание и хранение фото.
- Распознавание валют, кроме рубля.
